# Portfolio Assets

This directory stores public media used by the GitHub profile README.

## Expected GIF paths

```text
assets/projects/z-defense/gameplay.gif
assets/projects/act-normal/gameplay.gif
assets/projects/mood/gameplay.gif
assets/projects/crystalcore/gameplay.gif
```

## Recommended GIF format

- Length: 8–12 seconds
- Resolution: 960×540 or 1280×720
- Frame rate: 15–24 FPS
- Keep the file reasonably small for quick profile loading
- Show gameplay immediately; avoid long logos or title screens

After uploading a GIF, replace the corresponding placeholder block in the root `README.md` with:

```html
<p align="center">
  <img src="./assets/projects/PROJECT_FOLDER/gameplay.gif" alt="Project gameplay preview" width="100%" />
</p>
```
